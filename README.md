# 395 秋日路书

[打开交互路书](https://airollie.github.io/395-roadtrip/)

San Jose 出发，2026 年 10 月 9 日晚至 11 日，轿车，3 天 2 晚。

- 周六、周日 09:00–10:00 吃完早餐，10:00 开始观景和开车；主行程集中 June Lake／Mammoth。
- 周六 13:15 Lee Vining 午餐、18:30 Mammoth 晚餐；周日 13:30 Carson City 午餐、18:00 Placerville 晚餐，正常吃三餐。周日湖边短停后约 11:00 向北返程，目标 22:00–23:00 回 San Jose；实际随天气、通行及拥堵调整。
- 不安排长距离、高爬升徒步；湖岸散步 10–20 分钟，不走完整环湖。
- 不推荐湾区餐厅。周六、周日三餐各有 3 个照片选项，两晚各有 2 家酒店。
- 照片可放大、查看出处与踩坑；原始地图、31 个地点及 75 篇笔记截图保留在资料页。Bishop 只保留为下次旅行参考。
