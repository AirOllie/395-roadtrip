# 395 秋日路书

[打开交互路书](https://airollie.github.io/395-roadtrip/)

San Jose 出发，2026 年 10 月 9 日晚至 11 日，轿车，3 天 2 晚。

- 周六、周日 09:00–10:00 吃完早餐，10:00 开始观景和开车；主行程集中 Mono Lake／June Lake／Mammoth。
- 周六 13:15 Lee Vining 午餐、18:30 Mammoth 晚餐；周日 12:35 Lee Vining 午餐、18:45 Placerville 晚餐，正常吃三餐。周日 Hot Creek、Convict 短停后约 13:30 从 Lee Vining 向北返程，目标 23:00–24:00 回 San Jose；实际随天气、通行及拥堵调整。
- 周六：Conway 顺路短停 → Mono Lake South Tufa → Silver Lake；周日：Hot Creek → Convict Lake → 返程。
- 备选每日至多一站：周六 June Lake Overlook（+15–20 分钟），周日 Visitor Center 或 Bridgeport Courthouse（二选一，+10–15 分钟）。均有实景照片、来源、导航，默认跳过，额外耗时需顺延后续时间。
- 不安排长距离、高爬升徒步；湖岸散步 10–20 分钟，Mono South Tufa 平缓短线约 45 分钟，不走完整环湖。
- 不推荐湾区餐厅。周六、周日三餐各有 3 个照片选项，两晚各有 2 家酒店。
- 照片可放大、查看出处与踩坑；原始地图、31 个地点及 75 篇笔记截图保留在资料页。Bishop 只保留为下次旅行参考。
