- 两条典型路线：Bishop 追金黄、June Lake 看湖慢游。

- 可左右滑动比较吃住、选择喜欢的选项，照片可放大并追溯出处。
- 原来的地图、31 个地点、轿车筛选与 75 篇原帖截图保留在资料页。
