## 路线与 Fall Map 自动叠加（2026-10-08）

现在为同一张地图：行程编号与三天道路，叠加 California Fall Color 原图的彩色叶子，各图层可单独开关。点编号看时间、照片、导航与状态，点叶子看原图级别。原始地图保留为“看原图”入口。

9–11 月的后台每 6 小时自动读取公开地图发布内容，匹配其自身图例的六种图标，更新 `秋色状态.json` 与 `fall-state.js` 后发布 GitHub Pages；可在 [后台运行记录](https://github.com/AirOllie/395-roadtrip/actions/workflows/fall-map.yml) 查看结果。网页打开时读取最新数据，保持打开时每 5 分钟检查已发布的数据。后台同步不需要本机或 Codex 保持运行。

“自动更新”指跟进 Fall Map 当前发布版；原图通常周五更新，不是现场实时传感。每个景点标注级别、来源和成功同步时间；原图没有逐点观测日期，明确显示未注明。不存在于原图的景点灰色标为“原图未收录”，不套用邻近地点。June Lake Overlook 用 June Lake Loop 区域数据，明确标为区域参考。
